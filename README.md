# Technical exercise: Range component

A Next.js project with App Router and TypeScript for building a custom range component.

## Requirements

- A Node.js version compatible with the installed version of Next.js.
- pnpm.

## Installation and development

```bash
pnpm install
pnpm dev
```

The application will be available at [http://localhost:8080](http://localhost:8080). The project is in its initial stage: the exercise pages have not been implemented yet.

## Commands

```bash
pnpm lint          # Check the code with ESLint
pnpm format:check  # Check formatting without modifying files
pnpm format:fix    # Apply Prettier formatting
pnpm build         # Create a production build
pnpm start         # Run the production build on port 8080
```

The application code is in `src/`. This documentation will be expanded as the exercises are implemented.
